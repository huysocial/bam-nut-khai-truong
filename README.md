# Bấm Nút Khai Trương – VNPT

Tool nội bộ giúp VNPT các tỉnh/thành tự dựng 2 video nghi thức nhấn nút khai trương (File 1 – Màn chờ, File 2 – Kích hoạt) để chiếu lên màn LED sự kiện.

- Chạy: mở trang GitHub Pages của kho này bằng Chrome hoặc Edge trên máy tính.
- Bản đang đăng: **v1.4** (30/10/2026).
- File gốc và hồ sơ (URD, MAP, CHANGELOG) do Ban Truyền thông quản lý ở thư mục `1. APP/vnpt-bam-nut-khai-truong` trên Google Drive. Không sửa code trực tiếp trên GitHub.
- Bản GitHub Pages chưa có thư viện chung, khu Quản trị và nhật ký (chỉ chạy trên claude.ai).
